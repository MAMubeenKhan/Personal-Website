About

Most software never gets published. Mine does.

I am Mohammed Abdul Mubeen Khan, a solo developer working from India.

The distance between a working prototype and something a stranger can download is where most projects quietly die. Privacy policies, data-safety forms, permission justifications, trader verification, rejections that arrive with no explanation. I have crossed that distance on Google Play, the Microsoft Store and the Chrome Web Store, and I know what each of them asks for before it asks.

Lately that has meant tools for people at work: Screenshotline for developers who need screenshots of the web without running headless Chrome themselves, and AdLib for marketers who need Meta's Ad Library to be usable. Narrow tools, done properly, run by the person who built them.

I work fast, and AI tooling is a large part of how — but I read everything that ships, because the person who has to fix it in month six is me. Speed is not the pitch. Finishing is.
